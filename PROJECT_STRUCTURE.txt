================================================================================
BACKEND — server.js WORKFLOW
================================================================================

  1. Load .env
  2. validateSecurityConfig()
  3. connectDB()                    --> config/database.js --> MongoDB Atlas
  4. ensureRbacSeed()               --> creates roles + Super Admin
  5. seedSystemEmailTemplates()
  6. verifySmtpConnection()
  7. Mount routes:
       /api/auth
       /api/statistics
       /api/blogs
       /api/subscribers
       /api/settings
       /api/specialities
       /api/admin-management
  8. Serve static uploads:
       /uploads/blogs
       /uploads/profiles
       /uploads/specialities
       (clinical files = signed token download only)

================================================================================
AUTH + RBAC WORKFLOW
================================================================================

LOGIN FLOW:
  login/page.tsx
    --> POST /api/auth/login  { email, password, roleSlug }
    --> utils/auth.ts setAuth(token, admin)  [sessionStorage]
    --> redirect /dashboard

DASHBOARD ENTRY:
  app/dashboard/layout.tsx
    --> ProtectedDashboard  --> GET /api/auth/verify
    --> PermissionsProvider --> loads permissions
    --> DashboardRouteGuard --> checks module access per URL
    --> AdminLayout         --> Sidebar filters links by canViewModule()

API REQUEST (every protected call):
  utils/*Api.ts
    --> Authorization: Bearer <token from sessionStorage>
    --> backend middleware: protect --> attachPermissions --> requirePermission

LOGOUT:
  Sidebar logout
    --> POST /api/auth/logout
    --> utils/auth.ts clearAuth()
    --> redirect /login


================================================================================
DATA FLOW EXAMPLES
================================================================================

PUBLIC APPOINTMENT BOOKING:
  app/pages/Appointment/page.tsx
    --> utils (fetch) --> POST /api/statistics/appointments
    --> statisticsController.createAppointment
    --> Appointment model save
    --> emailService sends confirmation emails

BLOG PUBLISH:
  app/dashboard/Blogs/page.tsx
    --> blogsApi.uploadBlogImage --> POST /api/blogs/upload-image
    --> file saved to backend/uploads/blogs/
    --> blogsApi.createBlog --> POST /api/blogs
    --> public site reads GET /api/blogs/public

PUBLIC BLOG DISPLAY:
  app/pages/Blogs/[slug]/page.tsx
    --> blogsApi.fetchPublicBlogBySlug --> GET /api/blogs/public/:slug
    --> blogImageUrl() --> http://API/uploads/blogs/filename

IMAGE URL CHAIN:
  DB stores:        /uploads/blogs/1234-abc.jpg
  blogImageUrl():   NEXT_PUBLIC_API_URL + /uploads/blogs/1234-abc.jpg
  Browser loads:    Backend static file OR Next.js img remotePatterns

CLINICAL FILE (PRIVATE):
  Upload:   POST /api/statistics/appointments/:id/clinical-scans
  Storage:  backend/uploads/clinical/:appointmentId/:file
  Access:   Signed URL --> GET /api/statistics/clinical-scans/download?token=...
  NOT served from public /uploads/clinical static route
